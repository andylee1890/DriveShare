# DriveShare

DriveShare 是一个网盘资源分享索引，按“套”整理和展示相关的网盘链接。一套资源可能包含一个总入口，以及指向不同课程、目录或文件的多个链接。

## 如何使用

打开资源索引，选择感兴趣的分享套，再根据说明进入对应的网盘链接。链接可能来自不同的网盘平台，使用时请遵守对应平台的服务条款。

资源链接的可用状态会随着时间变化。遇到链接失效、需要登录、提取码变化或内容不完整时，请以网盘页面的实际情况为准。
